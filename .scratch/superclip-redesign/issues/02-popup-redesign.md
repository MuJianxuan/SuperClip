# 02 — Popup 重构（B2）

**What to build:** 菜单栏单击 / 全局快捷键唤起的剪贴板弹出面板按 B2 重做：
- 单行紧凑搜索框：搜索图标 + 输入 + 清空 × + 实际快捷键徽标，hover/focus 边框泛蓝
- 两行历史行：标题 13px 单行截断 + 预览 11px 单行截断 + 右侧时间 + 琥珀置顶星 + 类型色图标，行高 ≈46px，一屏 8-9 条
- 选中态：浅蓝底 + 左侧 3px 类型色条 + 图标染色
- **移除功能底栏**，改为单行纯信息（共 N 条 + 悬停预览提示），零按钮；窗口拖拽区迁移至搜索栏区域
- 悬停预览参数：200ms 延迟、150ms 容错、右侧优先（空间不足切左侧、clamp 视口内）、文本宽 280 / 图片宽 240
- 空态：无记录与搜索无结果两种文案
