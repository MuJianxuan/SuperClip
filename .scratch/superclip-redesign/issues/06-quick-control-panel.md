# 06 — Quick Control Panel（D2）

**What to build:** Tray 右键唤起的 232px 高频控制面板窗口（替代现有原生 Tray 菜单）：
- Rust 侧：新建无边框 panel 级面板窗口，定位在 tray 图标旁，点击外部 / Escape 关闭；tray 左键仍开 Popup、右键改为打开面板

- 面板状态与全局监听状态、默认粘贴模式设置实时联动
