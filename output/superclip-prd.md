# SuperClip 产品需求文档（P0修订版）

## 产品定位
面向 macOS arm 的本地剪贴板历史管理工具：菜单栏常驻、快速检索、快速粘贴、稳定优先、无云同步。

## 核心问题陈述
- 用户当前主要依赖“系统只保留一条剪贴板”“临时记事本”“聊天窗口自存”“反复切回来源应用”来回找内容，这会打断高频复制 / 粘贴流。
- 当文本、图片、文件、富文本混合出现时，用户很难稳定判断“这条内容还在不在”“能不能再次使用”“会不会因为权限或目标应用差异失败”。
- 现有复杂型剪贴板工具常把能力做重：云同步、团队协作、复杂收藏夹、AI 能力会引入额外心智负担；SuperClip 的目标是反向收敛到 **本地、快、稳、键盘优先**。
- 因此本产品不是“通用内容管理器”，而是面向高频再粘贴场景的 **本地剪贴板回取与再次执行工具**。

## 目标用户
- 频繁复制文本、图片、文件的个人用户
- 需要键盘优先操作的开发者、写作者、设计师
- 只想要一个靠谱、本地、不开云的开源工具的人

## JTBD / 核心使用任务
- 当我连续复制多段文本、命令或素材时，我想在不离开当前任务流的情况下快速找回任意一条，并在 2 次以内操作再次使用。
- 当我在不同应用之间处理图片、文件或富文本时，我想先看到可信的预览与明确动作边界，而不是靠猜测“这次粘贴会不会失败”。
- 当直接粘贴受限于 Accessibility 权限或目标应用兼容性时，我希望系统自动回退为仅复制，并用低打扰方式说明发生了什么。
- 当系统启动、崩溃恢复、迁移失败或多显示器定位异常时，我仍希望核心路径可用，而不是被异常状态直接卡死。

## 产品目标
1. 记录剪贴板历史（text / image / file / rich text，即 HTML / RTF）。
2. 提供全局快捷键快速呼出面板。
3. 支持“直接粘贴到当前应用”和“仅复制到剪贴板”两种路径。
4. 菜单栏单图标，内部分为“粘贴记录”和“功能列表”两组。
5. 本地 SQLite 持久化，稳定、可恢复、可裁剪。
6. 支持浅色 / 深色 / 跟随系统的主题切换。

## 非目标
- 不做云同步
- 不做多人协作
- 不做企业级权限体系
- 不做 AI 总结 / AI 搜索
- 不做跨平台首发（首发只做 macOS arm）

## 核心交互闭环（P0）
### 唤起
- 入口 1：菜单栏图标点击
- 入口 2：全局快捷键（默认 `Cmd+Shift+V`，可在设置中修改）
- 打开后默认聚焦搜索框；若存在历史项，则首条历史项默认高亮

### 键盘操作
- `↑ / ↓`：切换历史项
- `Enter`：执行当前默认动作（由设置决定：直接粘贴 / 仅复制）
- `Cmd+Enter`：执行相反动作
- `Space`：展开 / 收起右侧摘要
- `Delete / Backspace`：删除当前高亮项（搜索框内则保持输入编辑）
- `Esc`：关闭面板

### 结果区行为
- 左侧为历史列表
- 右侧为选中项摘要 + 功能列表
- 直接粘贴失败时，自动回退为“仅复制到剪贴板”并提示用户
- 删除单条后默认提供 30 秒撤销；超时后永久删除。
- 清空历史必须二次确认，不提供撤销。

### 置顶与整理（P0）
- 当前高亮项支持置顶 / 取消置顶。
- 置顶项固定在普通历史项之上，仍参与搜索与预览。
- P0 仅支持单条置顶 / 取消置顶，不做批量置顶。
- 建议置顶项数量不超过 50 条；超过时仍允许操作，但设置页需提示可能影响首屏检索效率。
- 置顶项内部按最近置顶时间倒序展示。

## MVP 功能
- 剪贴板监听 / 暂停监听
- 历史列表、搜索、置顶、删除、清空
- 图片预览、文件名预览、富文本摘要
- 全局快捷键唤起快速面板
- 选中记录后：直接粘贴 / 仅复制，可在设置切换
- 主题切换：浅色 / 深色 / 跟随系统
- 首启权限引导（Accessibility）
- 本地设置页：热键、保留数量、粘贴策略、主题、排除规则、开机启动
- 诊断导出、恢复模式、窗口定位回退与只读降级

## 设置与规则模型
- **热键**：默认 `Cmd+Shift+V`，支持冲突检测；若系统占用则引导用户重新绑定。
- **历史保留数量**：默认 1000，建议范围 100 ~ 5000。
- **粘贴策略**：默认“直接粘贴优先，失败回退为仅复制”。
- **主题**：`light` / `dark` / `system`。
- **排除规则**：按 App Bundle ID、内容类型、关键词三类配置；默认不做云端规则同步。
- **启动行为**：登录时启动 / 手动启动；是否“启动时自动显示”独立控制，默认关闭。
- **诊断能力**：支持导出最近错误与迁移状态，用于本地排障；诊断导出是 P0 能力，不作为独立持久化设置键。

### P0 设置冻结清单
| 项目 | 持久化 key | 阶段 | 默认值 | 说明 |
|---|---|---|---|---|
| 全局快捷键 | `global_shortcut` | P0 暴露 | `Cmd+Shift+V` | 支持录入、冲突检测、恢复默认 |
| 历史保留数量 | `history_limit` | P0 暴露 | `1000` | 建议范围 `100 ~ 5000` |
| 默认动作 | `default_action` | P0 暴露 | `direct_paste` | 可切换为 `copy_only` |
| 主题模式 | `theme_mode` | P0 暴露 | `light` | 支持 `light / dark / system` |
| 登录时启动 | `launch_at_login` | P0 暴露 | `false` | 更新失败不影响主流程 |
| 启动时自动显示 | `show_on_startup` | P0 暴露 | `false` | 只控制冷启动首屏是否自动展示 |
| 排除规则 | `exclusion_rules`（独立表） | P0 暴露 | 空列表 | 按 bundle id / content kind / keyword 三类管理 |
| 粘贴后恢复剪贴板延迟 | `restore_clipboard_delay_ms` | P1 预留 | `150` | 先冻结 key 与默认值，P0 首版不在设置页暴露 |
| 列表密度 | `density_mode` | P1 预留 | `comfortable` | P0 首版不暴露 |
| 行高 | `row_height_mode` | P1 预留 | `default` | P0 首版不暴露 |
| Hover 强度 | `hover_emphasis` | P1 预留 | `standard` | P0 首版不暴露 |
| 缩略图密度 | `thumbnail_density` | P1 预留 | `balanced` | P0 首版不暴露 |

- P0 首版设置页只展示 **P0 暴露** 项；所有 P1 预留项允许在 schema 中冻结，但不进入首版信息架构。
- 排除规则属于 P0 首版必须暴露的能力，但在存储层使用独立数据模型，不与 `settings` 表的标量键混存。
- “失败回退为仅复制”属于 P0 固定行为，不作为用户可关闭选项。

## P0 范围优先级（MoSCoW）
### Must
- 本地历史捕获（text / image / file / HTML / RTF）与去重入库
- 搜索、定位、高亮、置顶、删除、清空、删除后撤销
- 快捷键唤起、菜单栏唤起、搜索框默认聚焦
- `direct_paste` / `copy_only` 双动作模型与失败自动回退
- Accessibility 权限引导、恢复模式、诊断导出
- 登录时启动、启动时自动显示、多显示器与窗口回退边界

### Should
- 同一会话重开恢复搜索词、选中项、滚动位置
- 快捷键录入、冲突检测、恢复默认
- 置顶项数量告警、定位回退提示、启动集成失败 inline error

### Could
- 更细的展示密度、缩略图密度、hover 强度、行高偏好
- 更丰富的规则模板与导入能力

### Won't（P0 明确不做）
- 云同步、多人协作、企业权限体系
- AI 总结 / AI 搜索 / OCR
- 批量置顶、跨平台首发、文件 direct paste 承诺

## P0 功能完整性分析
| 功能域 | 解决的核心问题 | 当前文档覆盖状态 | 完整性判断 | 仍需实现阶段重点验证 |
|---|---|---|---|---|
| 采集与入库 | 复制后内容可回找、可去重、可长期保留 | 已覆盖内容类型、截断策略、排除规则、去重与保留上限 | 高 | 原生 pasteboard 适配细节、超限内容降级策略落地 |
| 检索与定位 | 用户能快速找到目标项 | 已覆盖排序、FTS、中文回退、高亮、会话内重开恢复 | 高 | 1k 样本下检索体验与高亮命中质量 |
| 执行动作 | 找到后能再次使用，而不是只“看见” | 已覆盖 copy-only / direct paste、失败自动回退、类型矩阵 | 高 | 图片 / 富文本在常见目标应用的兼容性边界 |
| 控制与治理 | 用户可控制历史规模与行为，而不是被工具反控 | 已覆盖暂停监听、置顶、删除、清空、设置冻结项 | 高 | 设置项变更后的即时生效与错误提示一致性 |
| 权限与引导 | 未授权时也不堵死主流程 | 已覆盖首启引导、顶部提示、重复引导策略 | 高 | 权限缺失场景的低打扰程度与转化率 |
| 稳定性与恢复 | 迁移失败、定位失败、崩溃后仍保持可用 | 已覆盖恢复模式、窗口回退、崩溃恢复、只读边界 | 中高 | 真实故障注入后的只读保护与恢复证据 |
| 诊断与排障 | 本地排障不依赖远端服务 | 已覆盖导出格式、脱敏规则、固定分段 | 中高 | 结构化日志字段与导出内容映射的一致性 |

- 本轮复审结论：P0 已不再缺少“核心功能类别”，当前主要剩余的是 **实现验证型风险**，而不是 **需求定义缺口**。
- 文档已从“happy path”扩展到“happy path + fallback + recovery + diagnostics”闭环，这对 P0 属于关键质量提升。
- P0 的明确边界已经锁定：**文件 direct paste 不承诺、AI 能力不进入首版、P1 展示密度类设置只冻结 schema 不暴露 UI**。

## 诊断导出（P0）
- 导出入口放在设置页 About / 关于分组。
- 导出格式默认使用单个 `superclip-diagnostics-<timestamp>.json` 文件；若后续需要附带截图或多文件日志，再升级为 zip。
- 导出内容至少包含：版本信息、系统版本、权限状态、最近错误、最近一次迁移状态、数据库健康摘要、当前设置摘要（脱敏后）。
- 导出前必须提醒“仅用于本地排障，可能包含来源应用名与错误上下文，不会自动上传任何远端服务”。
- 导出成功后给出保存路径与“复制路径”快捷动作；失败时给出可重试提示。
- 用户取消保存对话框时不视为错误，不打扰式提示。

### 诊断导出固定分段与脱敏要求
| 分段 | 是否包含 | 脱敏要求 |
|---|---|---|
| `app_info` | 必含 | 仅版本号、构建号、应用配置版本，不含剪贴板内容 |
| `os_info` | 必含 | 仅系统版本、芯片架构、语言环境 |
| `permissions` | 必含 | 仅权限状态与最近检查时间 |
| `migration_summary` | 必含 | 仅最近一次迁移结果、schema 版本、失败码 |
| `db_health_summary` | 必含 | 仅条目数、FTS 状态、文件大小区间、校验摘要 |
| `recent_errors` | 必含 | 最多最近 50 条；保留错误码与上下文标签，不带原始 payload |
| `settings_summary` | 必含 | 仅标量设置值、排除规则数量；不导出关键词明文与完整 bundle 列表 |
| `window_fallback_records` | 必含 | 最多最近 20 条定位回退记录，保留显示器与回退原因摘要 |

- 诊断导出 **禁止包含**：原始剪贴板文本、图片二进制、完整 HTML / RTF、文件实体内容、完整文件路径、排除规则关键词明文。
- 如需携带来源应用信息，仅允许导出应用名 / Bundle ID 摘要，不附带与具体剪贴板 payload 的一一对应关系。

## 存储与保留策略（P0）
- 文本 / HTML / RTF：优先保留原始内容
- 图片：保留可回贴所需的二进制内容
- 文件：保留文件 URL 与必要元数据，不复制文件实体本身
- 单项默认上限：文本类 2MB、图片 8MB、文件 URL 数组 20 条
- 超出上限的内容：只保留摘要、尺寸、来源、时间等元数据，不保留完整大字段
- 默认历史条数：1000 条
- 置顶项默认不参与自动淘汰
- 相同内容通过 hash 去重；重复复制仅更新 `last_seen_at` 与使用计数
- 定期清理后执行 `VACUUM / optimize`，避免数据库长期膨胀

## 权限与降级策略
- 未授予 Accessibility 时：
  - 仍可监听、搜索、浏览历史
  - 仅禁用“直接粘贴”
  - 面板顶部显示轻量提示，并提供“一键打开系统设置”入口
- 首次启动检测到未授权时，展示引导层
- 用户拒绝授权后，不连续打扰；仅在功能受阻时再次提示
- 设置页可随时重新触发授权引导

## 动作支持矩阵（P0）
| 内容类型 | 仅复制 | 直接粘贴 | 说明 |
|---|---|---|---|
| Text | 支持 | 支持 | 默认能力，作为 direct paste 成功基线 |
| HTML / RTF | 支持 | 条件支持 | 优先写入富文本格式并附 plain text；目标应用不接受富文本时允许退化为纯文本粘贴 |
| Image | 支持 | 条件支持 | 仅对支持标准图片 pasteboard 的目标应用做 best-effort direct paste |
| File | 支持 | P0 默认不承诺 | P0 统一走 copy-only，避免 Finder / IDE / 浏览器间行为不一致 |
| Unsupported / Truncated | 支持（若存在可复制摘要） | 不支持 | 明确展示“仅可复制摘要”或“仅可查看元数据” |

## 敏感内容与隐私策略
- 默认不联网、不做云同步、不做内容上传。
- 默认不做 OCR、语义总结或后台分析。
- 对密码管理器、一次性验证码、临时口令类内容，允许通过排除规则显式跳过入库。
- 对超大 payload 仅保留摘要与元数据，不保留完整原文时必须明确标记“已截断”。
- 前端默认只展示摘要与预览，原始 payload 仅在用户选中时按需读取。
- 不对用户剪贴板做静默清理，任何清理动作都必须可感知、可回退、可提示。

## 搜索与排序规则
- 默认排序：置顶项优先，其余按最近复制 / 最近使用倒序
- 搜索字段：原文、摘要、来源应用、文件名、HTML/RTF 转纯文本结果
- 命中优先级：精确匹配 > 前缀匹配 > 包含匹配 > 最近性
- 中文搜索采用 FTS + 归一化文本 + 包含匹配回退
- 命中词需要高亮

## 搜索上下文与重开规则（P0）
- 同一运行会话内，用户通过 `Esc`、点击外部区域或再次触发快捷键关闭主界面后，再次打开时保留上次搜索词、选中项与列表滚动位置，方便连续粘贴。
- 用户显式执行“清空搜索”后，应立即回到默认首项高亮状态，不保留旧搜索词。
- 用户完全退出应用后重新启动，默认不恢复上一次搜索词，避免敏感上下文被被动暴露。
- 当启用“登录时启动 + 启动时自动显示”时，首次展示仍使用空搜索初始态，不自动回放上一次搜索结果。

## 生命周期与系统集成
- 支持“登录时启动”
- 关闭窗口不退出，应用继续驻留菜单栏
- 退出需通过功能列表中的 Quit / 退出
- Dock 图标默认弱化或隐藏，保持菜单栏优先
- 崩溃后重启应自动恢复数据库与窗口状态
- 数据库迁移失败时进入恢复模式，优先保证历史可读

## 启动与窗口集成边界（P0）
- 用户开启“登录时启动”后，应用在下次登录时默认后台驻留菜单栏；除非用户显式打开“启动时自动显示”，否则不主动弹出主界面。
- 登录启动开关更新失败时，不影响主应用继续使用；设置页需显示 inline 错误并提供“重试”入口。
- 通过菜单栏点击或全局快捷键唤起时，主界面应尽量在当前触发显示器打开；无法判定时回退到主显示器。
- 若菜单栏贴边定位失败，允许回退为当前显示器上的居中工具窗口，但不能阻断搜索、浏览、复制等主流程。
- Dock 图标在 P0 不是主入口；即使发生窗口定位回退，也不应把产品交互重心切回 Dock。
- 若宿主环境无法完全隐藏 Dock 图标，则 Dock 仅作为次级唤起入口：点击后只允许唤起同一个主界面壳体，不创建第二套主窗口。
- 当用户通过 Dock 显式重新打开应用时，界面优先恢复最近一次可用显示器位置；若该显示器不可用，则回退到主显示器。

## 多显示器与安全区规则（P0）
- 优先使用当前活动显示器的菜单栏区域；若快捷键触发时目标应用位于副屏，则优先在副屏打开。
- 主界面不得被刘海区、菜单栏安全区或屏幕边缘裁切，搜索框与首行操作必须始终完整可见。
- 当可用宽度不足标准双栏布局时，自动进入紧凑模式；若紧凑模式仍无法完整展示，则回退为居中工具窗口。
- 布局降级只能影响展示密度，不能改变核心动作可达性：搜索、选中、复制、直接粘贴、设置入口必须仍然可访问。

## 恢复模式（只读）
- 迁移失败、数据库校验失败但历史仍可读取时，进入恢复模式（只读）。
- 恢复模式下允许：浏览历史、搜索、查看详情、仅复制、导出诊断。
- 恢复模式下禁止：直接粘贴、删除、清空历史、置顶变更、修改会写库的设置。
- 面板顶部必须明确提示“当前处于恢复模式，仅开放只读操作”，并提供“导出诊断”和“查看恢复说明”入口。

## 空状态与首屏文案规则（P0）
| 场景 | 标题方向 | 说明方向 | 主动作 |
|---|---|---|---|
| 首次自动显示（空搜索态） | 已准备就绪 | 说明应用已在菜单栏常驻，用户可直接复制内容后回来使用 | 保持焦点在搜索框，无强操作按钮 |
| 无历史 | 还没有剪贴板记录 | 引导用户先复制一段文本、图片或文件 | 保持搜索框可输入 |
| 搜索无结果 | 没找到匹配项 | 提示可清空搜索或换关键词 | 清空搜索 |
| 恢复模式（只读） | 当前处于恢复模式 | 明确只读、不会修改数据库、可继续浏览 / 搜索 / 复制 / 导出诊断 | 导出诊断 / 查看恢复说明 |

- 所有空状态文案都必须避免制造“故障感”，除恢复模式外默认使用中性说明，不误导用户认为应用异常。
- 首次自动显示与无历史是两个不同场景：前者强调“应用已就绪”，后者强调“还没有内容”。

## 核心假设与待验证项
- 文本 direct paste 是 P0 成功基线，必须在常见文本输入类应用中稳定成立。
- 图片 / HTML / RTF 的 direct paste 采用 best-effort；若目标应用兼容性不稳定，产品必须仍维持 copy-only 可用，而不是把兼容性问题转嫁给用户。
- 文件在 P0 统一定义为 copy-only，不因为个别 App 可用就反向扩 scope。
- 登录时启动、Dock reopen、多显示器定位等系统集成能力允许出现回退路径，但不允许破坏“搜索 / 浏览 / 复制”主链路。
- 诊断导出必须对本地排障足够有用，同时严格不携带原始 payload；这是隐私承诺与工程可观测性的双重约束。

## 实现阶段风险关闭标准（P0）
| 风险主题 | 当前风险 | 文档化决策 | 关闭标准 | 最低证据 |
|---|---|---|---|---|
| `direct_paste` 兼容性 | 不同目标应用对 text / rich text / image 的接受能力不一致 | P0 只把 `text` 作为强承诺，`html / rtf / image` 作为 best-effort，`file` 固定 `copy_only` | 每个内容类型都必须有“成功 / 退化 / 回退”的明确结果，不允许出现无反馈失败 | 类型分层兼容性矩阵 + 截图 / 结构化日志 / diagnostics / 手工验收记录 + 错误码 |
| 登录启动 / Dock reopen / 多显示器定位 | 系统集成波动大，容易出现打不开、开错屏、重复开窗 | 单窗口壳体、可回退、可记录、不阻断搜索 / 浏览 / 复制 | 任一入口失败时都能落到可用壳体，且不会生成第二主窗口 | 主屏 / 副屏 / Dock reopen / 显示器断开 4 类证据 |
| 诊断导出可用性 | 有 schema 但可能落地后字段不齐或不可排障 | 诊断导出按固定分段输出，结构化错误必须映射到导出 | 任一关键失败场景都能在导出中找到对应 error code 与上下文标签 | 导出样例 + 字段映射表 + 故障样本 |
| 恢复模式只读保护 | 文档定义了只读，但实现容易漏掉写路径 | 恢复模式禁止所有写库动作，并统一返回稳定错误码 | 在恢复模式下所有危险写操作都被拒绝，且用户能继续浏览 / 搜索 / 复制 / 导出诊断 | 失败注入脚本 / 截图 / 结构化日志 / diagnostics |

### 目标应用兼容性验证分层
| 分层 | 内容类型 | P0 承诺级别 | 代表性验证目标 | 允许的最终结果 |
|---|---|---|---|---|
| Tier A | Text | 强承诺 | 纯文本输入框、Terminal / IDE、系统输入区 | direct paste 成功；失败时必须回退 copy-only 并告知 |
| Tier B | HTML / RTF | 条件承诺 | 富文本编辑区、邮件正文、笔记类编辑器 | 保留富文本成功，或明确退化为 plain text |
| Tier C | Image | 条件承诺 | 支持图片粘贴的笔记 / 设计 / 文档输入区 | 图片 direct paste 成功，或 1 秒内回退为 copy-only |
| Tier D | File | 不承诺 direct paste | Finder / IDE / 浏览器上传区 | 仅验证 copy-only 与元数据预览，不做自动粘贴承诺 |

- 兼容性验证的目标不是“让所有 App 都 direct paste 成功”，而是 **让所有失败都以用户可理解的方式收口**。
- P0 验证以“常见目标类别”优先，不为单个特例 App 反向扩展产品范围。

## 成功标准
- 用户能在 2 次以内操作定位并再次使用任一历史项；`file` 类以“复制后可继续使用”为验收标准
- 应用重启后历史仍完整可用
- 暂停 / 恢复监听可即时生效
- 菜单栏与快捷键两条入口都能稳定工作
- 无授权时功能降级清晰，不阻断浏览历史

## 产品成功指标（P0 观察口径）
- **回取效率**：目标用户完成“打开 -> 搜索/选择 -> 再次使用”的主任务，P0 目标中位操作步数不超过 2。
- **主链路可用性**：`copy_only` 与 `direct_paste + fallback` 合并视角下，目标是“找到目标项后可再次使用”的链路成功率 ≥ 99%。
- **权限降级质量**：未授权用户仍可完成浏览 / 搜索 / 复制任务，且不会被重复阻断式弹窗打断。
- **恢复可信度**：迁移失败、定位失败、启动集成失败等异常均应保留可理解解释与可继续操作的替代路径。

## 工程验收标准
- 冷启动到可交互：目标不超过 3 秒（M 系列 Mac，正常安装环境）。
- 搜索 1000 条历史记录的首屏响应：目标 P95 不超过 120ms。
- 菜单栏唤起到面板聚焦：目标不超过 300ms。
- 监听空转 CPU：目标低于 5%。
- 常驻内存：目标低于 220MB。
- 直接粘贴失败时，必须在 1 秒内完成回退并给出可理解提示。
- 数据库迁移失败时，应用必须进入只读可浏览状态而不是直接退出。

### 风险关闭验收门（P0 必过）
- **兼容性门**：Tier A / B / C / D 四层都至少完成 1 轮证据采集；缺任何一层都不能宣称 P0 兼容性风险已关闭。
- **宿主集成门**：必须覆盖菜单栏点击、全局快捷键、Dock reopen、登录启动后首次展示、显示器切换 / 断开回退。
- **诊断门**：至少 4 类关键失败（权限缺失、窗口回退、迁移失败、direct paste 回退）都要能在诊断导出中定位到稳定 error code。
- **恢复门**：恢复模式下必须验证 `delete`、`clear`、`pin/unpin`、`settings:update` 被拒绝；浏览 / 搜索 / copy-only / 导出诊断保持可用。

### 性能验证与最低证据要求
- **冷启动**：从应用进程启动到 `tray-popover` 首次可交互，必须记录开始 / 结束时间戳，并保留日志截图或结构化日志。
- **搜索性能**：基于 1000 条历史记录固定样本集，至少执行 20 次代表性查询，输出 P50 / P95 / max。
- **菜单栏唤起**：至少覆盖主屏点击、副屏快捷键、Dock reopen 三类入口，各保留 1 份截图、结构化计时日志、diagnostics 或手工验收记录；录屏为可选增强证据。
- **CPU / 内存**：在监听空转 5 分钟窗口内采样；保留 Activity Monitor 截图或等价结构化统计。
- **直接粘贴失败回退**：至少提供 1 条失败后自动回退为仅复制的截图、结构化日志、diagnostics 或手工验收记录，并包含对应错误码。
- **恢复模式**：至少提供 1 份迁移失败进入只读模式的截图与诊断日志。

## 场景验收矩阵（P0）
| 场景 | 触发条件 | 预期结果 | 最低验收证据 |
|---|---|---|---|
| 菜单栏唤起 | 点击菜单栏图标 | 主界面在当前显示器可见，搜索框获得焦点 | 截图或结构化日志；录屏可选 |
| 副屏快捷键唤起 | 焦点应用位于副屏并触发热键 | 主界面优先在副屏打开；失败时回退为当前屏居中窗口 | 截图 / 定位日志 / 手工验收记录；录屏可选 |
| Dock reopen 去重 | 应用已驻留且用户从 Dock 再次打开 | 唤起同一个主界面壳体，不创建第二窗口 | window instance 日志 + 截图或手工验收记录；录屏可选 |
| 登录启动首屏 | 开启登录启动与启动时自动显示后重新登录 | 后台驻留或空搜索首屏符合设置，不回放旧搜索词 | presentation_reason 日志 + 截图或手工验收记录；录屏可选 |
| 无 Accessibility 权限 | 首次或运行中未授权 | 浏览 / 搜索 / 复制可用，直接粘贴禁用且有解释性提示 | 状态截图 + diagnostics 或结构化日志；录屏可选 |
| 富文本退化粘贴 | 目标应用不接受 HTML / RTF | 明确退化为 plain text 或 copy-only，且用户可继续完成任务 | `paste-failed` / degrade 日志 + 截图或手工验收记录；录屏可选 |
| 图片 direct paste 回退 | 目标应用不接受图片 pasteboard | 1 秒内回退为 copy-only，并给出明确提示 | 错误码 + 截图 / diagnostics / 手工验收记录；录屏可选 |
| 删除后撤销 | 删除单条历史并在 30 秒内撤销 | 条目恢复，排序与搜索结果重新可见 | restore 日志 + 截图或手工验收记录；录屏可选 |
| 诊断导出取消 | 打开保存面板后主动取消 | 不出现错误提示，不影响继续操作 | 手工验收记录或截图；录屏可选 |
| 诊断导出定位失败原因 | 发生窗口回退 / 权限缺失 / paste fallback 后执行导出 | 导出文件内可定位到对应 error code 与上下文标签 | 导出样例 + 截图 |
| 恢复模式进入 | 迁移失败但历史可读 | 进入只读模式，可浏览 / 搜索 / 复制 / 导出诊断 | 截图 + 诊断日志 |
| 恢复模式拒绝写操作 | 恢复模式下尝试 pin / delete / clear / settings:update | 全部被拒绝并返回只读说明，主界面不崩溃 | 错误日志 + diagnostics 或截图；录屏可选 |
