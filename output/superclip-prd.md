# SuperClip 产品需求文档（P0修订版）

## 产品定位
面向 macOS arm 的本地剪贴板历史管理工具：菜单栏常驻、快速检索、快速粘贴、稳定优先、无云同步。

## 目标用户
- 频繁复制文本、图片、文件的个人用户
- 需要键盘优先操作的开发者、写作者、设计师
- 只想要一个靠谱、本地、不开云的开源工具的人

## 产品目标
1. 记录剪贴板历史（text / image / file / rich text）。
2. 提供全局快捷键快速呼出面板。
3. 支持“直接粘贴到当前应用”和“仅复制到剪贴板”两种路径。
4. 菜单栏单图标，内部分为“粘贴记录”和“功能列表”两组。
5. 本地 SQLite 持久化，稳定、可恢复、可裁剪。
6. 支持浅色 / 深色 / 跟随系统的主题切换。

## 非目标
- 不做云同步
- 不做多人协作
- 不做企业级权限体系
- 不做 AI 总结 / AI 搜索
- 不做跨平台首发（首发只做 macOS arm）

## 核心交互闭环（P0）
### 唤起
- 入口 1：菜单栏图标点击
- 入口 2：全局快捷键（默认 `Cmd+Shift+V`，可在设置中修改）
- 打开后默认聚焦搜索框；若存在历史项，则首条历史项默认高亮

### 键盘操作
- `↑ / ↓`：切换历史项
- `Enter`：执行当前默认动作（由设置决定：直接粘贴 / 仅复制）
- `Cmd+Enter`：执行相反动作
- `Space`：展开 / 收起右侧摘要
- `Delete / Backspace`：删除当前高亮项（搜索框内则保持输入编辑）
- `Esc`：关闭面板

### 结果区行为
- 左侧为历史列表
- 右侧为选中项摘要 + 功能列表
- 直接粘贴失败时，自动回退为“仅复制到剪贴板”并提示用户
- 删除单条后默认提供 30 秒撤销；超时后永久删除。
- 清空历史必须二次确认，不提供撤销。

### 置顶与整理（P0）
- 当前高亮项支持置顶 / 取消置顶。
- 置顶项固定在普通历史项之上，仍参与搜索与预览。
- P0 仅支持单条置顶 / 取消置顶，不做批量置顶。
- 建议置顶项数量不超过 50 条；超过时仍允许操作，但设置页需提示可能影响首屏检索效率。
- 置顶项内部按最近置顶时间倒序展示。

## MVP 功能
- 剪贴板监听 / 暂停监听
- 历史列表、搜索、置顶、删除、清空
- 图片预览、文件名预览、富文本摘要
- 全局快捷键唤起快速面板
- 选中记录后：直接粘贴 / 仅复制，可在设置切换
- 主题切换：浅色 / 深色 / 跟随系统
- 首启权限引导（Accessibility）
- 本地设置页：热键、保留数量、粘贴策略、主题、排除规则、开机启动

## 设置与规则模型
- **热键**：默认 `Cmd+Shift+V`，支持冲突检测；若系统占用则引导用户重新绑定。
- **历史保留数量**：默认 1000，建议范围 100 ~ 5000。
- **粘贴策略**：默认“直接粘贴优先，失败回退为仅复制”。
- **主题**：`light` / `dark` / `system`。
- **排除规则**：按 App Bundle ID、内容类型、关键词三类配置；默认不做云端规则同步。
- **启动行为**：登录时启动 / 手动启动；是否“启动时自动显示”独立控制，默认关闭。
- **诊断开关**：可导出最近错误与迁移状态，用于本地排障。

## 诊断导出（P0）
- 导出入口放在设置页 About / 关于分组。
- 导出格式默认使用单个 `superclip-diagnostics-<timestamp>.json` 文件；若后续需要附带截图或多文件日志，再升级为 zip。
- 导出内容至少包含：版本信息、系统版本、权限状态、最近错误、最近一次迁移状态、数据库健康摘要、当前设置摘要（脱敏后）。
- 导出前必须提醒“仅用于本地排障，可能包含来源应用名与错误上下文，不会自动上传任何远端服务”。
- 导出成功后给出保存路径与“复制路径”快捷动作；失败时给出可重试提示。
- 用户取消保存对话框时不视为错误，不打扰式提示。

## 存储与保留策略（P0）
- 文本 / HTML / RTF：优先保留原始内容
- 图片：保留可回贴所需的二进制内容
- 文件：保留文件 URL 与必要元数据，不复制文件实体本身
- 单项默认上限：文本类 2MB、图片 8MB、文件 URL 数组 20 条
- 超出上限的内容：只保留摘要、尺寸、来源、时间等元数据，不保留完整大字段
- 默认历史条数：1000 条
- 置顶项默认不参与自动淘汰
- 相同内容通过 hash 去重；重复复制仅更新 `last_seen_at` 与使用计数
- 定期清理后执行 `VACUUM / optimize`，避免数据库长期膨胀

## 权限与降级策略
- 未授予 Accessibility 时：
  - 仍可监听、搜索、浏览历史
  - 仅禁用“直接粘贴”
  - 面板顶部显示轻量提示，并提供“一键打开系统设置”入口
- 首次启动检测到未授权时，展示引导层
- 用户拒绝授权后，不连续打扰；仅在功能受阻时再次提示
- 设置页可随时重新触发授权引导

## 动作支持矩阵（P0）
| 内容类型 | 仅复制 | 直接粘贴 | 说明 |
|---|---|---|---|
| Text | 支持 | 支持 | 默认能力，作为 direct paste 成功基线 |
| HTML / RTF | 支持 | 条件支持 | 优先写入富文本格式并附 plain text；目标应用不接受富文本时允许退化为纯文本粘贴 |
| Image | 支持 | 条件支持 | 仅对支持标准图片 pasteboard 的目标应用做 best-effort direct paste |
| File | 支持 | P0 默认不承诺 | P0 统一走 copy-only，避免 Finder / IDE / 浏览器间行为不一致 |
| Unsupported / Truncated | 支持（若存在可复制摘要） | 不支持 | 明确展示“仅可复制摘要”或“仅可查看元数据” |

## 敏感内容与隐私策略
- 默认不联网、不做云同步、不做内容上传。
- 默认不做 OCR、语义总结或后台分析。
- 对密码管理器、一次性验证码、临时口令类内容，允许通过排除规则显式跳过入库。
- 对超大 payload 仅保留摘要与元数据，不保留完整原文时必须明确标记“已截断”。
- 前端默认只展示摘要与预览，原始 payload 仅在用户选中时按需读取。
- 不对用户剪贴板做静默清理，任何清理动作都必须可感知、可回退、可提示。

## 搜索与排序规则
- 默认排序：置顶项优先，其余按最近复制 / 最近使用倒序
- 搜索字段：原文、摘要、来源应用、文件名、HTML/RTF 转纯文本结果
- 命中优先级：精确匹配 > 前缀匹配 > 包含匹配 > 最近性
- 中文搜索采用 FTS + 归一化文本 + 包含匹配回退
- 命中词需要高亮

## 搜索上下文与重开规则（P0）
- 同一运行会话内，用户通过 `Esc`、点击外部区域或再次触发快捷键关闭主界面后，再次打开时保留上次搜索词、选中项与列表滚动位置，方便连续粘贴。
- 用户显式执行“清空搜索”后，应立即回到默认首项高亮状态，不保留旧搜索词。
- 用户完全退出应用后重新启动，默认不恢复上一次搜索词，避免敏感上下文被被动暴露。
- 当启用“登录时启动 + 启动时自动显示”时，首次展示仍使用空搜索初始态，不自动回放上一次搜索结果。

## 生命周期与系统集成
- 支持“登录时启动”
- 关闭窗口不退出，应用继续驻留菜单栏
- 退出需通过功能列表中的 Quit / 退出
- Dock 图标默认弱化或隐藏，保持菜单栏优先
- 崩溃后重启应自动恢复数据库与窗口状态
- 数据库迁移失败时进入恢复模式，优先保证历史可读

## 启动与窗口集成边界（P0）
- 用户开启“登录时启动”后，应用在下次登录时默认后台驻留菜单栏；除非用户显式打开“启动时自动显示”，否则不主动弹出主界面。
- 登录启动开关更新失败时，不影响主应用继续使用；设置页需显示 inline 错误并提供“重试”入口。
- 通过菜单栏点击或全局快捷键唤起时，主界面应尽量在当前触发显示器打开；无法判定时回退到主显示器。
- 若菜单栏贴边定位失败，允许回退为当前显示器上的居中工具窗口，但不能阻断搜索、浏览、复制等主流程。
- Dock 图标在 P0 不是主入口；即使发生窗口定位回退，也不应把产品交互重心切回 Dock。
- 若宿主环境无法完全隐藏 Dock 图标，则 Dock 仅作为次级唤起入口：点击后只允许唤起同一个主界面壳体，不创建第二套主窗口。
- 当用户通过 Dock 显式重新打开应用时，界面优先恢复最近一次可用显示器位置；若该显示器不可用，则回退到主显示器。

## 多显示器与安全区规则（P0）
- 优先使用当前活动显示器的菜单栏区域；若快捷键触发时目标应用位于副屏，则优先在副屏打开。
- 主界面不得被刘海区、菜单栏安全区或屏幕边缘裁切，搜索框与首行操作必须始终完整可见。
- 当可用宽度不足标准双栏布局时，自动进入紧凑模式；若紧凑模式仍无法完整展示，则回退为居中工具窗口。
- 布局降级只能影响展示密度，不能改变核心动作可达性：搜索、选中、复制、直接粘贴、设置入口必须仍然可访问。

## 恢复模式（只读）
- 迁移失败、数据库校验失败但历史仍可读取时，进入恢复模式（只读）。
- 恢复模式下允许：浏览历史、搜索、查看详情、仅复制、导出诊断。
- 恢复模式下禁止：直接粘贴、删除、清空历史、置顶变更、修改会写库的设置。
- 面板顶部必须明确提示“当前处于恢复模式，仅开放只读操作”，并提供“导出诊断”和“查看恢复说明”入口。

## 空状态与首屏文案规则（P0）
| 场景 | 标题方向 | 说明方向 | 主动作 |
|---|---|---|---|
| 首次自动显示（空搜索态） | 已准备就绪 | 说明应用已在菜单栏常驻，用户可直接复制内容后回来使用 | 保持焦点在搜索框，无强操作按钮 |
| 无历史 | 还没有剪贴板记录 | 引导用户先复制一段文本、图片或文件 | 保持搜索框可输入 |
| 搜索无结果 | 没找到匹配项 | 提示可清空搜索或换关键词 | 清空搜索 |
| 恢复模式（只读） | 当前处于恢复模式 | 明确只读、不会修改数据库、可继续浏览 / 搜索 / 复制 / 导出诊断 | 导出诊断 / 查看恢复说明 |

- 所有空状态文案都必须避免制造“故障感”，除恢复模式外默认使用中性说明，不误导用户认为应用异常。
- 首次自动显示与无历史是两个不同场景：前者强调“应用已就绪”，后者强调“还没有内容”。

## 状态系统
- 正常监听
- 已暂停
- 无历史
- 搜索无结果
- 权限缺失
- 写入中 / 索引更新中
- 数据写入失败
- 直接粘贴失败
- 恢复中 / 迁移中
- 恢复模式（只读）

## 成功标准
- 用户能在 2 次以内操作定位并粘贴任一历史项
- 应用重启后历史仍完整可用
- 暂停 / 恢复监听可即时生效
- 菜单栏与快捷键两条入口都能稳定工作
- 无授权时功能降级清晰，不阻断浏览历史

## 工程验收标准
- 冷启动到可交互：目标不超过 3 秒（M 系列 Mac，正常安装环境）。
- 搜索 1000 条历史记录的首屏响应：目标 P95 不超过 120ms。
- 菜单栏唤起到面板聚焦：目标不超过 300ms。
- 监听空转 CPU：目标低于 5%。
- 常驻内存：目标低于 220MB。
- 直接粘贴失败时，必须在 1 秒内完成回退并给出可理解提示。
- 数据库迁移失败时，应用必须进入只读可浏览状态而不是直接退出。

## 场景验收矩阵（P0）
| 场景 | 触发条件 | 预期结果 | 最低验收证据 |
|---|---|---|---|
| 菜单栏唤起 | 点击菜单栏图标 | 主界面在当前显示器可见，搜索框获得焦点 | 录屏或截图 + 日志 |
| 副屏快捷键唤起 | 焦点应用位于副屏并触发热键 | 主界面优先在副屏打开；失败时回退为当前屏居中窗口 | 录屏 |
| 无 Accessibility 权限 | 首次或运行中未授权 | 浏览 / 搜索 / 复制可用，直接粘贴禁用且有解释性提示 | 录屏 + 状态截图 |
| 删除后撤销 | 删除单条历史并在 30 秒内撤销 | 条目恢复，排序与搜索结果重新可见 | 录屏 + 日志 |
| 诊断导出取消 | 打开保存面板后主动取消 | 不出现错误提示，不影响继续操作 | 录屏 |
| 恢复模式进入 | 迁移失败但历史可读 | 进入只读模式，可浏览 / 搜索 / 复制 / 导出诊断 | 截图 + 诊断日志 |
