SuperClip · macOS 菜单栏剪贴板应用 · 三方向设计 canvas

把主面板控制在真实窗口尺寸里，再谈视觉风格。

这版不是营销页，而是给 SuperClip 的菜单栏主界面、设置页和权限引导做三套可比较的 UI 方向。 所有方案都遵守同一套产品边界：本地优先、键盘优先、双栏工作区、copy-only / direct paste 双动作， 并把主面板尺寸压在可放进 mac 菜单栏回退窗口的范围内。

主面板尺寸
推荐 864×640；安全区不足时降到 744×560 的紧凑模式，再不行回退到居中工具窗口。
设置窗口
更高的纵向窗口，优先装下热键、排除规则、启动行为、诊断导出，不挤压主面板。
冻结系统
Lucide / Inter + SF Pro fallback / shadcn-ui + Radix + Tailwind / tray-popover + settings + permission-guide。
功能边界
不做云同步、不做 AI，总体是一个能快速找回、再次执行、失败可回退的本地回贴工具。

已冻结的设计系统

先锁图标、字体、token、组件生态和页面骨架，再比较视觉方向。

图标库
Lucide 风格线性图标。按钮里优先使用明确图标，不靠花哨装饰。
字体系统
Inter + SF Pro fallback；等宽内容用 SF Mono / ui-monospace。
设计 token
只用语义 token，不直接把颜色硬编码成紫粉渐变或浏览器默认蓝。
组件生态
shadcn/ui + Radix + Tailwind，保持 mac 工具感，不做卡片堆叠。
页面骨架
tray-popover 为默认主界面，settings 为纵向配置窗，permission-guide 负责 Accessibility 引导。
