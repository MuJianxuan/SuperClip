# 2026-10-20 开发记录

## 22:44 启动期 Dock 图标闪动修复
- 目的：`npm run tauri dev` 启动时 Dock 会先弹出应用图标再消失，改为启动即不出现图标。
- 变更：
  - 新增 `src-tauri/Info.plist` 写入 `LSUIElement=true`：dev 下由 `tauri-codegen` 嵌入二进制 `__TEXT,__info_plist` 段，打包时合并进 `.app` 的 Info.plist，LaunchServices 侧不再生成 Dock 图标。
  - `run()` 在 `build()` 之后、`app.run()` 之前新增 macOS `set_activation_policy(Accessory)`（`let app` 改为 `let mut app`）：tao 在 `applicationDidFinishLaunching` 会无条件 `setActivationPolicy(Regular)` 覆盖 `LSUIElement`，此调用让 tao 的初始策略直接为 Accessory，消除启动中那一帧 Foreground 切换。
  - 既有 `apply_macos_dock_policy`（`set_dock_visibility(false)`）保留为兜底，行为不变；主窗口/托盘/快捷键等运行态行为不变（运行态原本即 UIElement）。
- 涉及：`src-tauri/Info.plist`、`src-tauri/src/lib.rs`
- 状态：未完成（剩余：`npm run tauri build` 打包验证未执行）
