  • 重复规则会被后端 UNIQUE(kind,value) 拦住并提示已存在
  • 默认规则可停用但不可删除（删除无意义，重启会重新下发）
  • 行操作菜单：编辑 / 删除
设计要点
  • 「来源」列区分默认与自定义，让用户知道哪些改动会被系统覆盖
  • 隐私说明放在底部而非顶部：规则页本身就是隐私承诺的证据

⑱ 操作反馈
功能
  • 成功反馈：深色胶囊 + 图标 + 文案（已复制到剪贴板）
  • 降级反馈：白底描边胶囊 + 警示图标 + 原因（富文本降级为纯文本）
  • 可撤销反馈：深色胶囊 + 「撤销」文字按钮，5 秒后自动消失
交互
  • 同一时刻只显示一个反馈，新反馈替换旧反馈
  • 点「撤销」立即恢复并显示确认
  • 反馈不阻塞操作，不夺焦点
设计要点
  • 区分「成功」与「降级」两种语气：降级必须让用户知道内容形态变了
  • 删除这类不可逆操作必须有撤销通道（后端 undo_token 已具备）
